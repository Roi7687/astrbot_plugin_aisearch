# astrbot-plugin-aisearch

> **AI搜索** — 基于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 的 DeepSeek 联网搜索 / 图片理解插件
>
> 版本 v2.3.1 ｜ 作者 Roi ｜ 许可证 AGPL-3.0

通过**自动化操控 DeepSeek Chat 网页端**（cloakbrowser 反检测无头浏览器）实现联网搜索与图片理解，**不调用任何 API**：@机器人 直接提问即可，结果以 Markdown 返回。

## ✨ 特性

- **零指令触发**：@机器人（或私聊）发文字、图片、引用消息即可提问；指令只用于会话管理
- **引用消息解析**：引用（回复）一条消息再提问，**被引用的文本与图片**一并送给 AI
- **图文同会话**：文字与图片在同一会话中处理，可先文字提问、再发图追问，上下文连续
- **深度思考默认开启**：每次提问前幂等开启，无需任何参数；智能搜索跟随 DeepSeek 网页端设置
- **回答不串轮**：发送前采样回复块基线，等本轮新回复渲染并稳定后才返回，深度思考延迟输出也不会拿到上一轮回答
- **慢速网络适配**：图片上传双路确认（网络请求 + DOM 标志）后才发送；流式输出真正结束才返回完整结果
- **多会话持久化**：本地 id 管理会话，空闲自动静默销毁（不推送通知）；自动跳过机器人自身消息与指令消息
- **QQ 键盘按钮**：结果附带快捷按钮（仅 QQ 官方平台，其余平台自动回退纯文本）

## 📦 安装

1. 将本仓库放入 AstrBot 的 `data/plugins/` 目录（`git clone` 或下载解压），也可通过 AstrBot 插件市场安装
2. 安装依赖：`pip install -r requirements.txt`
3. 重启 AstrBot

## 🚀 使用

### 首次登录

发送 `/cloak登录`，按提示使用微信扫码。凭证持久化保存（auth_state.json），之后无需重复登录。

### 提问方式

| 场景 | 操作 |
|------|------|
| 群聊提问 | `@机器人 今天有什么大新闻` |
| 私聊提问 | 直接发送文字 |
| 引用提问 | 引用（回复）一条消息 + `@机器人 回答一下这个问题` |
| 图片理解 | `@机器人` + 图片（可附带文字）；私聊直接发图 |

> 群里未 @机器人 的消息不会被拦截，不影响正常群聊；只发图片不带文字时使用默认提示词；只引用消息没打字时针对被引用内容作答。

### 指令 `/ais`（别名：`搜索`）

| 指令 | 说明 |
|------|------|
| `/ais <问题>` | 在当前会话提问（无会话自动创建） |
| `/ais new` | 新建会话（reset / 重置），旧会话保留 |
| `/ais list` | 会话列表（列表 / 状态 / session），👉 为当前，已关闭的不显示 |
| `/ais switch <id>` | 按本地 id 切换会话（切换），如 `/ais switch 2` |
| `/ais help` | 帮助（帮助） |
| `/cloak登录` | 微信扫码登录 DeepSeek |

## ⚙️ 配置

编辑 `core/config.py`：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `AUTO_TRIGGER` | `True` | 关闭后纯文字消息不再自动触发（图片、引用图片仍处理） |
| `IDLE_TIMEOUT_SECONDS` | `300` | 会话空闲自动销毁时间（秒） |
| `MAX_IMAGE_BYTES` | `8MB` | 单张图片超过该大小自动压缩（Pillow，1024px / JPEG q70） |
| `DEFAULT_IMAGE_PROMPT` | 请详细描述这张图片的内容。 | 只发图片不带文字时的默认提问 |
| `DEFAULT_QUOTE_PROMPT` | 请针对我引用的这条消息进行回答。 | 只引用消息、自己没打字时的默认提问 |

## 🧩 会话机制

- 会话由插件**本地递增 id**（1、2、3…）标识，持久化到 conversations.json；没有任何存活会话时 id 归 1，不会无限增长
- 会话首次使用时惰性创建，空闲超时（默认 300 秒，每次提问 / 切换都会重置计时）后自动销毁，服务器端会话一并删除，**全程静默、不推送通知**
- 插件重启后未销毁的会话仍可 `/ais list` 查看、`/ais switch <id>` 切回；插件禁用 / 重载时取消计时器并关闭浏览器内核

## ⚠️ 注意事项

- 依赖 DeepSeek 网页版 UI，若网页改版导致选择器失效，需要更新 `core/session_core.py` 中的定位逻辑
- 本插件通过浏览器自动化驱动 DeepSeek 网页端，请合理使用，避免高频请求触发风控
- DeepSeek 官方已把「快速 / 专家 / 识图模式」合并为统一对话，插件不区分模式：文本与图片都在当前会话处理

## 🧪 测试

`tests/` 下的脚本不依赖浏览器，可直接运行（如 `python tests/test_quote_parser.py`），覆盖指令解析、引用消息解析、会话核心与端到端消息处理。
