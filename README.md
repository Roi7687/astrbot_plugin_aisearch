# astrbot-plugin-aisearch

> **AI搜索** — 基于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 的 DeepSeek 联网 AI 搜索 / 识图插件
>
> 版本：v2.2.7 ｜ 作者：Roi ｜ 许可证：AGPL-3.0

通过**自动化操控 DeepSeek Chat 网页端**（cloakbrowser 反检测无头浏览器），无需调用任何 API，即可在 QQ 等聊天平台直接使用 DeepSeek 的**联网搜索**与**识图模式**能力。

## ✨ 特性

- **自动触发（v2.2.0）**：@机器人（或私聊）直接发文字/图片即可自动联网提问，无需任何指令；仅切换/新建会话时使用指令
- **深度思考 / 联网搜索跟随 DeepSeek 网页端设置**：默认开启，无需插件干预
- **统一指令 /ais**：会话管理（列表 / 切换 / 新建）一个指令搞定
- **持久化会话**：自动创建新会话，支持上下文连续追问；空闲超时（默认 300 秒）自动静默销毁（不推送通知，避免刷屏）
- **识图模式**：群聊中 @机器人 + 发送图片（可附带文字），或私聊直接发图，自动进入 DeepSeek 网页版「识图模式」会话
- **最新回答保障（v2.2.0）**：连续多轮对话时按「回复块计数」精确定位最新一条回答，不会返回旧结果
- **慢速网络适配（v2.2.1）**：识图上传双路确认（网络请求 + DOM 标志）完成后才发送提问；回答流式输出真正结束（停止按钮/流式光标消失）后才返回完整结果
- **静默不刷屏（v2.2.2）**：会话超时静默销毁，无主动推送通知；自动过滤机器人自身消息，防自我回复循环
- **QQ 键盘按钮**：结果附带快捷按钮（仅 QQ 官方平台）

## 📦 安装

1. 将本仓库放入 AstrBot 的 addons 目录（或通过 AstrBot 插件市场安装）
2. 安装依赖：pip install -r requirements.txt
3. 重启 AstrBot

## 🚀 使用

### 首次登录

`/cloak登录`

按提示微信扫码完成身份验证，凭证将持久化保存（auth_state.json）。

### 自动触发（⚡ 推荐）

| 场景 | 操作 | 说明 |
|------|------|------|
| 群聊提问 | `@机器人 今天有什么大新闻` | 自动进入 AI 搜索对话，无需指令 |
| 私聊提问 | 直接发送文字 | 自动进入 AI 搜索对话 |
| 识图 | `@机器人` + 图片（或私聊发图） | 自动进入识图会话 |
| 切换会话 | `/ais switch <id>` | 仅需要切换/新建会话时使用指令 |

> 深度思考与联网搜索跟随 DeepSeek 网页端设置（默认开启）；不 @机器人 的群聊消息不会被拦截（不影响正常群聊）。

### 统一指令 /ais（别名：搜索）

| 指令 | 说明 |
|------|------|
| `/ais <问题>` | 在当前会话联网提问（无会话自动创建） |
| `/ais -v <问题>` | 切到「识图模式」会话提问（无则自动创建） |
| `/ais new`（reset / 重置） | 开启新会话（旧会话保留，可按 id 切回） |
| `/ais list`（列表 / 状态 / session） | 查看全部会话（每个会话带**本地 id**，👉 为当前） |
| `/ais switch <id>`（切换） | 按本地 id 切换会话，如 `/ais switch 2` |
| `/ais switch 识图/普通` | 切换到该模式最近使用的会话（无则新建） |
| `/ais list <id>` | 列表便捷切换（等同于 `/ais switch <id>`） |
| `/ais help`（帮助） | 显示帮助 |

> 💡 会话 id 由插件**本地计数**（1、2、3...），与 DeepSeek 网页端的会话 ID 无关，重启后保持连续。

### 识图模式（🖼）

- **群聊**：@机器人 并发送一张或多张图片，可附带文字提问 → 自动进入识图会话
- **私聊**：直接发送图片即可
- 图片过大时自动压缩（Pillow，1024px / JPEG q70）后上传
- 之后在识图会话中可直接 @机器人 发文字/图片继续追问，无需 /ais

### 示例

`@机器人 今天有什么大新闻`
`@机器人 解释量子纠缠的原理`
`@机器人 帮我看看这张图的配色`（发图）
`/ais list`
`/ais switch 2`

## ⚙️ 配置

编辑 core/config.py：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| AUTO_TRIGGER | True | 自动触发（@机器人/私聊直接提问，无需 /ais） |
| IDLE_TIMEOUT_SECONDS | 300 | 会话空闲自动销毁时间（秒） |
| MAX_IMAGE_BYTES | 8MB | 单张图片超过该大小自动压缩 |
| DEFAULT_VISION_PROMPT | 请详细描述这张图片的内容。 | 仅发图不带文字时的默认提问 |

## 🧩 会话机制

- 插件内部维护**多个会话**（普通 / 识图混合），每个会话有一个**本地递增 id**（1、2、3...），持久化到 conversations.json
- 会话首次使用时惰性创建，记录会话 ID / URL / 消息数 / 本地 id
- `/ais list` 查看全部会话，`/ais switch <id>` 按本地 id 切换；已关闭的会话按 id 切换时**自动重建**
- 会话空闲超时后自动销毁（服务器端删除会话），**静默进行、不推送通知**
- 插件重启后未销毁的会话仍可通过 /ais list / /ais switch 切回

## ⚠️ 注意事项

- 依赖 DeepSeek 网页版 UI，若网页改版导致选择器失效，需要更新 core/session_core.py 中的定位逻辑
- 识图模式为 DeepSeek 官方功能（model_type=vision），若账号未开放会提示不可用
- 本插件通过浏览器自动化驱动 DeepSeek 网页端，请合理使用，避免高频请求触发风控
